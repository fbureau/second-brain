# 06-knowledge/_sources/

Ingested produced documents (`type: doc`) live here — strategy docs, analyses, reports,
decks, specs, external articles captured by `doc-ingest`.

They are kept out of the root of `06-knowledge/` so the durable knowledge (wiki pages,
lessons, domain hubs) stays readable as the vault grows.

## Naming convention

`YYYY-MM-DD-<slug>.md` (dated — the ingestion date).

## Schema

See `_CLAUDE.md` at the vault root, type schema `doc`.

## Associated skill

`doc-ingest` writes here; the curator lists each doc in its domain hub.
