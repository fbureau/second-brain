# 02-people/

Strategic CRM. One note per person you interact with regularly.

## Naming convention

`First Last.md` (spaces allowed, normal case)

Examples:
- `Alex Rivera.md`
- `Jordan Park.md`
- `Sam Lee.md`

## Special rules

1. **Append-only on the timeline** — never overwrite.
2. **Compiled truth** editable but sparingly + recency markers.
3. **Fuzzy match before create** — always.
4. **No delete** — leavers go to `07-archive/` or stay with `status: alumni`.

## Required schema

See `_CLAUDE.md`, section "Type schemas > type: person".

## Associated skill

`people-update` is the main skill that writes here.
